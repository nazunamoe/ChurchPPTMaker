# 예배 순서 PPT 제작 프로그램 (ChurchPPTMaker)

예배 순서를 화면에서 끌어다 놓아 구성하면, 순서마다 맞는 PowerPoint 파일을 찾아 **한 개의 예배 PPT로 자동 병합**해 주는 Windows 프로그램입니다.

- 기도·찬송·말씀·설교·CCM·사용자 지정 순서를 **드래그&드롭**으로 배치
- 찬송가 장 번호로 찬송가 PPT를 **폴더에서 자동 검색**
- 파일 이름이 제각각인 CCM PPT는 CCM 폴더에서 **곡명으로 검색해서 선택** (초성 검색 가능)
- 성경 구절(`요3:16`, `롬1-3` 등)을 [Bible2PPT](https://github.com/nazunamoe/Bible2PPT)로 **자동 생성**
- 기도자 이름 등 문구를 템플릿의 지정 위치에 **자동 입력**
- 원본 템플릿의 **서식·폰트·애니메이션·레이아웃·배경을 그대로 유지**하며 병합
- 주일오전/주일오후/수요예배 등 순서 조합을 **프리셋**으로 저장·불러오기
- 결과 파일 이름 자동 지정: `2026-10-11_사랑교회_주일오전예배.pptx` — 형식은 자유롭게 바꿀 수 있고 **프리셋별로 따로 저장**
- Windows 11 스타일 UI, 라이트/다크 모드 지원

## 1. 요구 사항

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10 / 11 |
| PowerPoint | Microsoft PowerPoint 설치 필수 (2016 이상 권장) |
| Python | 3.10 이상 (소스로 실행하거나 빌드할 때만 필요) |

## 2. 설치 및 실행 (소스 코드)

```powershell
cd ChurchPPTMaker
pip install -r requirements.txt
python main.py
```

처음 실행하면 프로그램 폴더에 다음이 자동으로 만들어집니다.

```
config.json     사용자 설정
presets.json    예배 순서 프리셋 (기본 3종: 주일오전예배, 주일오후예배, 수요예배)
templates\      순서별 PPT 템플릿 폴더
hymns\          찬송가 PPT 폴더
ccm\            CCM PPT 폴더
prayers\        기도 템플릿 폴더 (합심기도.pptx, 중보기도.pptx …)
output\         완성된 예배 PPT 저장 폴더
```

## 3. 빌드 (실행 파일 .exe 만들기)

Python이 없는 교회 컴퓨터에서도 쓸 수 있도록 하나의 `.exe` 파일로 만들 수 있습니다.

**`build.bat`을 더블클릭**하거나 PowerShell에서 실행하면 됩니다.

```powershell
cd ChurchPPTMaker
.\build.bat           # 처음 실행 시 .venv 가상환경 생성 → 패키지 설치 → exe 빌드
.\build.bat -Clean    # build\, dist\ 를 지우고 새로 빌드
.\build.bat -Version 1.2.0   # 버전을 1.2.0 으로 올린 뒤 빌드
```

**버전 관리**: 버전은 `version.py` 의 `__version__` 한 곳에서 관리합니다. 화면 제목(`… v1.2.0`)과
exe 파일 속성(탐색기 [속성] → [자세히]의 파일/제품 버전)에 같은 값이 들어갑니다.
`-Version` 을 주면 `version.py` 를 고친 뒤 빌드하고, 생략하면 현재 버전 그대로 빌드합니다. 형식은 `주.부.수정`(예: `1.2.0`).

`build.bat`은 실행 정책과 관계없이 `build.ps1`을 실행하며, `build.ps1`은 다음을 자동으로 처리합니다.
1. 프로그램 폴더에 `.venv` 가상환경 생성 (이미 있으면 재사용)
2. `requirements-build.txt` 설치 (실행 패키지 + PyInstaller)
3. `version.py` 로 exe 버전 정보 파일(`build\version_info.txt`) 생성
4. PyInstaller로 단일 exe 빌드

직접 빌드하려면:

```powershell
pip install -r requirements-build.txt
python version.py --write-info build\version_info.txt
pyinstaller --noconfirm --onefile --windowed --name ChurchPPTMaker --version-file build\version_info.txt --collect-data customtkinter main.py
```

- 결과물: `dist\ChurchPPTMaker.exe` (약 14MB)
- `--collect-data customtkinter`는 UI 테마 파일을 포함하기 위해 **반드시** 필요합니다.
- exe를 처음 실행하면 `config.json`, `presets.json`, `templates\`, `hymns\`, `ccm\`, `output\`이 **exe와 같은 폴더**에 만들어집니다.
  다른 컴퓨터로 옮길 때는 exe와 함께 이 파일·폴더들을 같이 복사하면 설정과 템플릿이 그대로 유지됩니다.
- 빌드 중 생기는 `build\` 폴더와 `ChurchPPTMaker.spec` 파일은 지워도 됩니다.

> 빌드할 컴퓨터에도 PowerPoint가 있을 필요는 없지만, **exe를 실행하는 컴퓨터에는 PowerPoint가 설치되어 있어야** 합니다.

## 4. 처음 설정하기

### 설정 마법사
처음 실행하면 **설정 마법사**가 자동으로 열려 아래 4-1~4-3 을 차례로 안내합니다.

| 단계 | 지정하는 것 |
|---|---|
| 1. 폴더 | 템플릿·기도·찬송가·CCM 폴더 (폴더마다 찾은 PPT 개수 표시) |
| 2. 설교 | 설교 템플릿 PPT 파일 |
| 3. 말씀 | Bible2PPT.exe(지정하면 역본 목록을 불러옴), 기본 성경 역본·두 번째 역본, 성경 템플릿, 슬라이드당 줄 수 |
| 4. 확인 | 지정한 내용 요약 — 빠진 것은 ⚠ 로 표시 |

- **[마침]**을 눌러야 저장됩니다. **[나중에 하기]**(또는 Esc)로 닫으면 아무것도 바뀌지 않습니다.
- 처음 한 번만 자동으로 열리고, 그 뒤에는 제목 옆 **[설정 마법사]** 버튼으로 언제든 다시 열 수 있습니다.
- 마법사 없이 아래처럼 ⚙ 설정에서 직접 지정해도 됩니다.

### 4-1. 폴더 지정
상단 **[⚙ 설정]** → **폴더**에서 📁 버튼으로 템플릿·기도·찬송가·CCM·출력 폴더를 지정하고 **[저장]**을 누릅니다.
(↗ 버튼은 해당 폴더를 탐색기로 엽니다. 메인 화면 상단에는 저장될 위치가 표시되고 **[출력 폴더 열기 ↗]**로 바로 열 수 있습니다.)

| 폴더 | 넣을 파일 |
|---|---|
| 템플릿 | 순서별 PPT (`예배로 부름.pptx`, `축도.pptx` …) — [템플릿 파일] 목록에 표시됨 |
| 기도 | 기도 종류별 PPT (`합심기도.pptx`, `중보기도.pptx` …) — 4-2 참고 |
| 찬송가 | 찬송가 PPT (하위 폴더까지 검색) |
| CCM | CCM PPT (하위 폴더까지 검색, 파일 이름은 자유) |
| 출력 | 완성된 예배 PPT가 저장될 곳 |

### 4-2. 기도 · 설교 템플릿 지정
기도는 합심기도·중보기도·대표기도처럼 종류가 여러 가지라 **폴더**로 지정합니다.
1. `합심기도.pptx`, `중보기도.pptx`처럼 기도 종류별 PPT를 한 폴더에 넣습니다.
2. **[⚙ 설정]** → 폴더의 `기도` 줄에서 📁로 그 폴더를 지정합니다 (기본: 프로그램 폴더의 `prayers\`).
3. 기도를 추가할 때 이 폴더의 PPT 중 하나를 **기도 종류**로 고릅니다. 순서 목록 왼쪽에는 고른 이름(예: `합심기도`)이 표시됩니다.

설교는 템플릿이 하나이므로 상단 **[⚙ 설정]** → **[Bible2PPT · 설교]** 쪽의 `설교 템플릿 (.pptx)`에서 **PPT 파일 하나**를 지정합니다.

기도 폴더가 없거나 비어 있으면, 또는 설교 템플릿을 지정하지 않으면 기도·설교를 추가할 때 오류가 표시됩니다.

### 4-3. Bible2PPT 연결 (말씀 기능)
1. **명령줄 실행을 지원하는** [Bible2PPT](https://github.com/nazunamoe/Bible2PPT)를 준비합니다.
   (원본 Bible2PPT 2.0.4 이하처럼 창으로만 쓰는 버전을 지정하면 "명령줄 실행을 지원하지 않는 버전" 안내가 표시됩니다.)
2. 상단 **[⚙ 설정]** → `Bible2PPT.exe 경로`에서 **[찾기]**로 exe를 지정합니다.
   지정하는 즉시 사용 가능한 **역본 목록을 자동으로 불러옵니다** (인터넷에서 받아오므로 잠시 걸릴 수 있음).
3. `기본 성경 역본` 옆 **🔍**로 역본을 검색해 고릅니다 (아래 6-3의 역본 검색 참고). 역본은 `개역개정 · 갓피아 [1]`처럼 **이름 · 소스 [ID]**로 표시되며,
   같은 이름이 여러 소스에 있어도 ID로 정확히 구분됩니다. 필요하면 성경용 템플릿(.pptx), 슬라이드당 줄 수도 지정합니다.
4. 설정 창의 역본 칸 아래에 `역본 N종`이 표시되면 완료입니다.
   Bible2PPT를 지정하지 않은 상태에서 말씀을 추가하면 먼저 지정하라는 오류가 표시됩니다.
   역본 목록은 저장해 두었다가 다음 실행 때 그대로 쓰며, 역본이 추가된 경우 `기본 성경 역본` 옆 ↻ 버튼으로 다시 불러옵니다.

## 5. 템플릿 PPT 준비 규칙

### 5-1. 파일 이름 = 순서 이름
순서 목록 왼쪽 이름과 **같은 이름의 파일**을 템플릿 폴더에서 찾습니다. 띄어쓰기는 무시합니다.

```
[예배로 부름] → templates\예배로 부름.pptx   (또는 예배로부름.pptx)
[축도]        → templates\축도.pptx
[합심기도]    → prayers\합심기도.pptx   (기도 폴더)
[설교]        → 설정의 설교 템플릿 PPT
```

### 5-2. 문구가 들어갈 자리 지정
순서 오른쪽 값(기도자 이름, 인도자, 설교 제목 등)을 템플릿에 넣으려면 둘 중 하나를 사용합니다.
한 항목에 최대 3개(`{{내용1}}~{{내용3}}`)까지 넣을 수 있습니다.

| 항목 | `{{내용1}}` | `{{내용2}}` | `{{내용3}}` |
|---|---|---|---|
| 기도 | 기도자 이름 | | |
| 찬송 | 장 번호 (예: `29장`) | | |
| 사용자 지정 | 내용1 (오른쪽 문구) | 내용2 | 내용3 |
| 설교 | 설교 제목 | 설교자 | |

사용자 지정 항목을 추가·수정하는 창에는 **내용1·내용2·내용3 칸**이 있습니다. 템플릿의 `{{내용1}}~{{내용3}}`
(또는 이름이 `내용1~내용3`인 텍스트 상자) 자리에 각각 들어가며, 고른 템플릿에서 찾은 자리가 창 아래에 안내됩니다.

1. **치환 문구**: 텍스트 상자에 `{{내용1}}`이라고 적어 두면 그 부분이 바뀝니다. 글꼴·색상 등 서식은 그대로 유지됩니다.
   예) `대표기도: {{내용1}}` → `대표기도: 홍길동 장로`, `{{내용1}} / {{내용2}}` → `믿음의 사람 / 홍길동 목사`
2. **텍스트 상자 이름**: PowerPoint [홈] → [정렬] → [선택 창]에서 텍스트 상자 이름을 `내용1`, `내용2`로 바꾸면 그 상자의 글자가 통째로 바뀝니다.

예전 템플릿의 `{{내용}}`(상자 이름 `내용`)도 그대로 `{{내용1}}`처럼 동작합니다.

치환 문구와 상자 이름은 ⚙ 설정에서 바꿀 수 있습니다.

**빈 칸일 때**: 항목에 값을 넣지 않은 자리(예: 사용자 지정의 내용2)는 ⚙ 설정 → **빈 칸일 때 기본값**의
`{{내용1}}~{{내용3}}` 문구가 들어갑니다. 기본값도 비어 있으면 `{{내용2}}` 같은 토큰 글자를 지워서 결과에 남지 않게 합니다.

### 5-3. 모든 슬라이드에 자동 입력되는 문구
아래 문구는 어느 템플릿에 있든 자동으로 바뀝니다.

| 문구 | 바뀌는 값 |
|---|---|
| `{{교회이름}}` | 교회 이름 |
| `{{날짜}}` | 예배 날짜 (YYYY-MM-DD) |
| `{{년}}` `{{월}}` `{{일}}` | 예배 날짜의 연·월·일 (예: `2026`, `10`, `4` — 앞에 0을 붙이지 않음) |
| `{{요일}}` | 예배 날짜의 요일 한 글자 (예: `일`) |
| `{{예배종류}}` | 예배 종류 |

예) `{{년}}년 {{월}}월 {{일}}일 {{요일}}요일` → `2026년 10월 4일 일요일`, `{{년}}. {{월}}. {{일}}. {{요일}}` → `2026. 10. 4. 일`
파일 이름 형식과 같은 항목이지만, 파일 이름의 `{월}` `{일}`은 정렬이 되도록 `10`, `04`처럼 0을 붙입니다.

### 5-4. 찬송가 파일 이름
`29장`을 찾을 때 다음 순서로 검색합니다.

1. 파일 이름이 정확히 `29`, `029`, `29장`, `029장`
2. 파일 이름의 **첫 번째 숫자**가 29 — 예) `새찬송가 029장 성도여 다함께.pptx`
3. 숫자 없이 곡명을 입력한 경우 → 파일 이름에 곡명이 포함된 파일

## 6. 사용 방법

화면은 **상단(교회 이름·날짜·예배 종류) / 왼쪽(템플릿 파일 관리) / 오른쪽(순서) / 하단(생성 버튼)**으로 구성됩니다.
폴더·파일 이름 형식·화면 모드처럼 한 번 정하면 거의 바꾸지 않는 것은 **[⚙ 설정]**에 있습니다.
창 맨 위 제목 줄을 끌면 창이 옮겨지고, 두 번 누르면 최대화/복원됩니다 (오른쪽 위 ─ □ ✕ 버튼).
프로그램 제목 오른쪽 **[? 도움말]**에서 이 사용법(템플릿 규칙·자동 문구·문제 해결 등)을 목차와 검색으로 볼 수 있습니다.
오른쪽 "순서" 패널은 최초 UI 초안의 배치를 그대로 따릅니다.

### 6-1. 기본 정보 입력 (상단)
- **교회 이름**: 한 번 입력하면 저장되어 다음 실행 때도 유지됩니다.
- **날짜**: 직접 입력하거나 📅 버튼으로 달력에서 선택, **[오늘]**로 오늘 날짜를 입력합니다.
- **예배 종류**: 파일 이름에 들어갑니다. 프리셋을 불러오면 프리셋 이름으로 자동 입력됩니다.
- 그 아래에 **저장될 위치**(출력 폴더 + 파일 이름)가 표시됩니다. **[출력 폴더 열기 ↗]**로 출력 폴더를 탐색기에서 엽니다.
- **파일 이름 형식**: **[⚙ 설정]** → **결과 파일 이름**에서 정합니다. `{항목}` 자리에 값이 들어가며, 아래에 실제 파일 이름이 미리 표시됩니다.
  **[항목 ▾]**으로 커서 위치에 항목을 넣고, **[기본값]**으로 `{날짜}_{교회이름}_{예배종류}`로 되돌립니다.

  | 항목 | 들어가는 값 (2026-10-11 기준) |
  |---|---|
  | `{날짜}` | `2026-10-11` |
  | `{년}` `{월}` `{일}` | `2026` `10` `11` |
  | `{요일}` | `일` |
  | `{교회이름}` | 교회 이름 |
  | `{예배종류}` | 예배 종류 |

  예) `{년}{월}{일} {예배종류}` → `20261011 주일오전예배.pptx`. 파일 이름에 쓸 수 없는 문자(`\ / : * ? " < > |`)는 자동으로 빠집니다.
  파일 이름 형식은 **프리셋을 저장할 때 함께 저장**되고, 프리셋을 불러오면 그 프리셋의 형식으로 바뀝니다 (예: 수요예배만 다른 형식).

### 6-2. 예배 순서 만들기 (오른쪽 "순서" 패널)
- 아래쪽 **[기도] [찬송] [말씀] [설교] [CCM] [사용자 지정]** 버튼을 순서 목록 위 원하는 위치로 **끌어다 놓습니다**.
  버튼을 그냥 클릭하면 맨 아래에 추가됩니다.
- 추가할 때 입력 창이 뜹니다. **필수 항목을 비우면 오류**가 표시됩니다.

  | 버튼 | 입력 내용 | 호출되는 PPT |
  |---|---|---|
  | 기도 | 기도 종류 (필수, 기도 폴더의 PPT 중 선택), 기도자 이름 (필수) | 고른 기도 템플릿 + 이름 자동 입력 |
  | 찬송 | 찬송가 장 (필수, `29` 또는 `29장`) | 찬송가 폴더에서 검색 |
  | 말씀 | 성경 구절 (필수), 역본·두 번째 역본 (선택) | Bible2PPT로 생성 (두 번째 역본을 고르면 두 역본을 나란히) |
  | 설교 | 설교 제목 (필수), 설교자 (필수) | 설정의 설교 템플릿 + 제목·설교자 자동 입력 |
  | CCM | CCM 폴더의 파일을 곡명으로 검색해 선택 (필수) | 선택한 CCM PPT 그대로 |
  | 사용자 지정 | 템플릿 PPT (필수, 템플릿 폴더의 파일을 검색해 선택), 내용1~3 (선택) | 고른 템플릿 PPT |

- 순서에 넣는 곳은 이 버튼들뿐입니다. [사용자 지정] 창에서 템플릿을 고르면 그 템플릿에 있는 입력 자리(`{{내용1}}` 등)를 알려 줍니다.
- 왼쪽 **[템플릿 파일]**은 [사용자 지정]에 쓰는 PPT 를 관리하는 곳입니다. 파일을 **더블클릭**하면 PowerPoint로 엽니다.

  | 버튼 | 동작 |
  |---|---|
  | PPT 추가 | 다른 곳에 있는 PPT를 템플릿 폴더로 **복사**해 목록에 추가 (원본은 그대로, 여러 개 선택 가능) |
  | 열기 | 선택한 템플릿을 PowerPoint로 열어 수정 |
  | 삭제 | 선택한 템플릿을 템플릿 폴더에서 삭제 (확인 후 **휴지통**으로 이동 — 되살릴 수 있음) |
  | 폴더 ↗ | 템플릿 폴더를 탐색기로 열기 |
- 순서 편집
  - `⋮⋮` 손잡이를 끌어 위치 변경, **▲ ▼**로 한 칸씩 이동, **✕**로 삭제
  - 항목의 이름이나 오른쪽 값을 클릭하면 바로 수정 창이 뜹니다
  - 행 오른쪽 **[열기]**는 원본 PPT를 PowerPoint로 엽니다. 수정해서 저장하면 다음 생성부터 반영됩니다.
    - 기도·설교·사용자 지정: 해당 템플릿
    - 찬송·CCM: 찾은 찬송가·CCM PPT
    - 말씀: Bible2PPT로 그 구절 PPT를 만들어 엽니다 (임시 폴더에 저장되며 하루 뒤 정리됨)
  - **[전체 비우기]**로 목록 초기화
  - **[↶ 되돌리기]**(또는 `Ctrl+Z`)로 방금 한 추가·수정·이동·삭제·비우기·프리셋 적용·파일 불러오기를 되돌림 (최근 30번까지.
    입력칸에 글자를 쓰는 중에는 `Ctrl+Z` 가 순서를 건드리지 않음)
  - 만들던 순서는 자동으로 보관되어 **프로그램을 닫았다 켜도 그대로** 나옵니다. 새로 시작하려면 [전체 비우기]나 프리셋 고르기
  - 곡 제목처럼 내용이 길어 한 줄에 안 들어가면 오른쪽 칸이 아랫줄로 내려가고, 그래도 길면 끝을 '…' 로 줄여 보여 줍니다
    (창을 넓히면 다시 한 줄로). 전체 내용은 칸을 눌러 수정 창에서 볼 수 있습니다.

### 6-3. 말씀 (성경 구절)
**[말씀]** 버튼을 순서 목록으로 끌어다 놓거나 클릭하면 입력 창이 뜹니다. 구절을 입력하고, 필요하면 역본을 고릅니다.
역본 칸을 비워 두면 ⚙ 설정의 **기본 성경 역본**(과 두 번째 기본 역본)을 씁니다.

**두 역본 나란히 보기** — **두 번째 역본** 칸에 역본(예: `KJV`)을 고르면 한 슬라이드에 두 역본이 나란히 들어갑니다
(Bible2PPT 의 `-b 역본1 -b 역본2`). 첫 번째 역본만 고르면 그 역본 하나만 씁니다.
⚙ 설정의 **두 번째 기본 역본**을 정해 두면 역본을 비운 말씀은 모두 두 역본으로 만들어집니다.

**역본 검색** — 역본 칸 옆 **🔍** 버튼 (말씀 항목 입력 창, ⚙ 설정의 기본 역본에도 있음)

| 검색 예 | 찾는 역본 |
|---|---|
| `개역개정` / `ㄱㅇㄱㅈ` | 이름 (한글 초성만 입력해도 됨) |
| `kjv`, `NIV` | 약어 (대소문자 무시) |
| `개역한글 youversion` | 여러 단어는 모두 포함하는 역본 (이름·소스·ID) |

- 위쪽 **[전체] [갓피아] [GOODTV] [YouVersion]**으로 소스별로 거를 수 있습니다.
- ↑↓로 이동, Enter 또는 더블클릭으로 선택, Esc로 취소합니다. **[기본값 사용]**은 역본 칸을 비웁니다(설정의 기본 역본 사용).
- 역본 칸에 이름을 직접 입력해도 됩니다 (예: `개역개정`).

**구절 형식** (Bible2PPT 규칙)

| 입력 | 의미 |
|---|---|
| `창` | 창세기 전체 |
| `창1` | 창세기 1장 |
| `롬1-3` | 로마서 1~3장 |
| `요3:16` | 요한복음 3장 16절 |
| `창1:1-5` | 창세기 1장 1~5절 |
| `사1:3-3:9` | 이사야 1장 3절 ~ 3장 9절 |
| `요3:16, 롬8:28` | 여러 구절 (쉼표로 구분) |

`요 3:16`처럼 띄어 써도 자동으로 정리됩니다.

### 6-4. 프리셋 (순서 패널 위쪽)
| 조작 | 동작 |
|---|---|
| 프리셋 목록에서 고르기 | 바로 그 프리셋으로 순서를 교체 (지금 순서가 있으면 바꿀지 확인). 예배 종류·파일 이름 형식도 함께 |
| 프리셋으로 저장 | 이름을 물어보고 지금 순서를 저장 (지금 프리셋 이름이 미리 들어감, 같은 이름이면 덮어쓰기 확인). 지금 프리셋을 고친 상태(**● 수정됨**)면 이름을 묻지 않고 그 프리셋에 저장할지만 확인 ([아니오] = 다른 이름으로 저장) |
| 삭제 | 지금 고른 프리셋을 확인 후 삭제 (순서 목록은 그대로) |

- 프리셋을 불러온 뒤 순서나 파일 이름 형식을 고치면 프리셋 이름 옆에 **● 수정됨**이 붙습니다. 프리셋 자체는 [프리셋으로 저장]을
  눌러야 바뀝니다 (매주 찬송 장·구절만 바꿔 쓰는 것은 저장하지 않아도 됨).
- 고치던 중에 프로그램을 닫아도 **다시 켜면 순서와 함께 '어느 프리셋을 고치던 중'인지 그대로** 나오므로 이어서 저장할 수 있습니다.
- 수정됨 상태에서 프리셋을 고르면 저장하지 않은 내용이 있다고 알려 줍니다 (같은 프리셋을 고르면 저장된 내용으로 되돌리기).
  실수로 바꿨으면 [↶ 되돌리기]로 순서와 프리셋 표시가 함께 돌아옵니다.
- 프리셋은 **최대 10개**, 이름은 **10글자 이내**입니다.
- 프리셋에는 순서와 함께 상단의 **파일 이름 형식**도 저장됩니다.
- 프리셋과 별도로, "순서" 제목 줄 오른쪽의 **[순서 파일 ▾]** → 파일에서 순서 불러오기 / 순서를 파일로 내보내기로 순서를 텍스트(.txt) 파일로 주고받을 수 있습니다.
  불러올 때 교회 이름·예배 종류·날짜도 함께 채워지며, 현재 순서를 교체하거나(예) 아래에 추가하거나(아니오) 그만둘 수 있습니다(취소).

### 6-5. PPT 생성 (하단)
1. **[예배 PPT 병합 및 생성]**을 누릅니다.
2. 교회 이름·날짜·예배 종류·순서와 필요한 파일이 모두 있는지 먼저 검사합니다. 빠진 것이 있으면 한꺼번에 알려 줍니다.
   같은 이름의 결과 파일이 PowerPoint 에 열려 있어 덮어쓸 수 없을 때도 여기서 바로 알려 줍니다 (닫고 다시 하거나 [미리 보기] 사용).
3. 만드는 동안 **생성 중 화면**이 진행 상황과 경과 시간을 보여 줍니다. 작업 중 PowerPoint가 **화면에 보이지 않게** 실행됩니다.
   ⚠ 다 만들 때까지 **PowerPoint를 사용하지 마세요** — 그사이 PowerPoint에서 다른 파일을 열거나 누르면 슬라이드가 그 파일에 붙을 수 있습니다.
   생성 중에도 창 옮기기·최소화는 되지만, 순서·설정은 바꿀 수 없습니다.
   1분 넘게 진행이 없으면(말씀은 Bible2PPT 제한 시간 + 30초) **응답 없음 안내**가 나옵니다. 처음 설치한 Office 의 라이선스 동의·로그인 창이나
   PowerPoint 오류 창이 숨어 있는 경우가 많으니 **[PowerPoint 창 보기]**로 떠 있는 창을 앞으로 가져와 닫으면 계속됩니다.
   **[생성 중단]**은 이번 생성 때 켜진 PowerPoint 를 강제로 끕니다 (생성 전부터 켜져 있던 PowerPoint 는 끄지 않음).
   만드는 중에 프로그램을 닫으면(확인 후) 만드는 데 쓰던 PowerPoint 를 끄고 종료합니다. 생성 전부터 켜져 있던 PowerPoint 로
   만드는 중이면 창만 닫히고 **다 만든 뒤에** 종료합니다 — 보이지 않는 PowerPoint 가 남지 않게 하기 위함입니다.
4. 완료되면 출력 폴더에 상단 **파일 이름** 형식대로(기본 `YYYY-MM-DD_교회이름_예배종류.pptx`) 저장됩니다.
   **[생성 후 열기]**가 체크되어 있으면 작업한 PowerPoint에서 바로 열립니다 (다시 실행하지 않아 빠름).
   **[열 때 슬라이드 쇼로 시작]**도 체크하면 첫 슬라이드부터 **바로 슬라이드 쇼**가 시작됩니다
   (Esc로 쇼를 끝내면 편집 화면이 남음).
   결과 PPT의 **슬라이드 비율**은 **[⚙ 설정]** → PPT 병합에서 고릅니다.

   | 선택 | 결과 |
   |---|---|
   | 원본 | 첫 번째 순서 PPT의 크기를 그대로 사용 (기본값) |
   | 16:9 | 와이드 화면. 4:3 원본은 내용 크기 그대로 가운데에 놓이고 양옆이 빔 |
   | 4:3 | 표준 화면. 16:9 원본은 내용이 비율대로 줄어들고 위아래가 빔 |

   PowerPoint의 [슬라이드 크기] → [맞춤 확인]과 같은 방식이라 내용이 잘리지 않습니다.
5. 경고(예: 문구 넣을 자리를 못 찾음)가 있으면 상태 줄에 표시되며, **[로그]** 버튼으로 자세한 내용을 볼 수 있습니다.

**미리 보기 (저장 안 함)**

생성 버튼 아래 **[미리 보기 (저장 안 함)]**을 누르면 출력 폴더에 저장하지 않고 임시 파일로 만들어 **바로 엽니다**.
미리 확인하거나 한 번만 쓸 PPT 를 만들 때 출력 폴더가 지저분해지지 않습니다.
- [열 때 슬라이드 쇼로 시작]을 켜 두면 바로 쇼로 시작합니다. ([생성 후 열기]와 관계없이 항상 엽니다.)
- 임시 파일은 `%LOCALAPPDATA%\ChurchPPTMaker\임시` 에 `이름_시분초.pptx` 로 만들어지며, **최근 10개**(⚙ 설정에서 1~100 변경)만
  보관하고 오래된 것부터 자동으로 지웁니다. PowerPoint 에서 열려 있는 파일은 지우지 않습니다.
- 하단 **[임시 파일]** 버튼으로 지난 임시 파일을 다시 불러옵니다.

  | 버튼 | 동작 |
  |---|---|
  | 열기 (더블클릭·Enter) | PowerPoint 로 열기 |
  | 슬라이드 쇼 | 바로 쇼로 시작 |
  | 다른 이름으로 저장 | 원하는 곳에 저장 (기본: 출력 폴더, 시분초를 뗀 이름). 템플릿 등 원본 폴더·임시 폴더에는 저장할 수 없음 |
  | 폴더 열기 | 임시 폴더를 탐색기로 열기 |

  PPT 를 만드는 중에는 임시 파일·템플릿을 PowerPoint 로 열 수 없습니다 (만드는 중인 PPT 의 슬라이드가 연 파일로 붙여질 수 있음).

## 7. 설정 (⚙ 설정 / config.json)

설정 창은 한 쪽에 모든 항목이 있고, 위아래로 스크롤해서 볼 수 있습니다.

| 항목 | 설명 | 기본값 |
|---|---|---|
| 폴더 | 템플릿·기도·찬송가·CCM·출력 폴더 (4-1 참고) | 프로그램 폴더의 templates·prayers·hymns·ccm·output |
| 결과 파일 이름 | 파일 이름 형식 (6-1 참고) | `{날짜}_{교회이름}_{예배종류}` |
| Bible2PPT.exe 경로 | Bible2PPT 실행 파일 위치 | (없음) |
| 기본 성경 역본 | 역본을 따로 고르지 않았을 때 사용 | Bible2PPT 마지막 선택값 |
| 두 번째 기본 역본 | 기본 역본과 나란히 넣을 역본 (선택) | (없음) |
| 성경 템플릿 | Bible2PPT에 넘길 .pptx 템플릿 | Bible2PPT 기본 템플릿 |
| 슬라이드당 줄 수 | 0~9 (0 = 제한 없음) | Bible2PPT 설정 |
| 실행 제한 시간 | Bible2PPT 응답 대기 시간(초) | 180 |
| 설교 템플릿 | 설교에 쓸 PPT 파일 하나 | (없음 — 지정해야 설교 추가 가능) |
| 병합 방식 | 아래 표 참고 | 원본 서식 유지 |
| 치환 토큰 | 문구 자리 기본형 (번호를 붙여 `{{내용1}}~{{내용3}}`) | `{{내용}}` |
| 텍스트 상자 이름 | 치환 토큰이 없을 때 쓸 상자 이름 기본형 (`내용1~내용3`) | `내용` |
| 빈 칸일 때 기본값 | `{{내용1}}~{{내용3}}` 값이 비었을 때 넣을 문구 (비우면 토큰을 지움) | (없음) |
| 슬라이드 비율 | 결과 PPT 비율: 원본(첫 PPT 크기) / 16:9 / 4:3 — 내용이 잘리지 않게 맞춤 (6-5 참고) | 원본 |
| 임시 파일 최대 보관 개수 | [미리 보기]로 만든 PPT 를 최근 것부터 몇 개 보관할지 (1~100) | 10 |
| 화면 모드 | 라이트 / 다크 / 시스템(Windows 설정을 따름) | 시스템 |
| Windows 강조 색 사용 | Windows [개인 설정 → 색]의 강조 색을 버튼·선택 표시 색으로 사용 (끄면 파란색, 다시 켤 때 적용) | 켬 |

**병합 방식**

| 방식 | 특징 |
|---|---|
| 원본 서식 유지 (권장) | PowerPoint의 [원본 서식 유지] 붙여넣기를 그대로 사용. 테마·배경(그림 포함)까지 완벽히 유지. 작업 창은 화면에 띄우지 않음 |
| 창 없이 병합 | PowerPoint 창을 전혀 띄우지 않음. 단색 배경은 정확히 복사, 그라데이션·그림 배경은 고해상도 이미지로 대체 |

교회 이름·예배 종류는 메인 화면에서 바꾸면 자동 저장됩니다. 그 밖의 설정은 **[저장]**을 눌러야 반영됩니다.

`config.json` 에는 설정과 함께 **마지막으로 작업하던 순서**(`last_items` — 기도자·설교자 이름 포함)가 들어 있습니다.
프로그램 폴더를 다른 사람에게 통째로 줄 때는 `config.json`·`presets.json` 을 빼고 주면 내 설정·이름이 따라가지 않습니다.

## 8. 문제 해결

| 증상 | 해결 방법 |
|---|---|
| "템플릿 폴더에 'OOO.pptx' 없음" | 순서 이름과 파일 이름이 같은지 확인 (띄어쓰기는 무시됨) |
| "CCM 폴더에서 PPT를 찾지 못함" | 선택했던 CCM 파일이 지워졌거나 이름이 바뀜 → 항목을 클릭해 다시 선택 |
| "찬송가 폴더에서 PPT를 찾지 못함" | 파일 이름에 장 번호가 첫 번째 숫자로 들어 있는지 확인 (5-4 참고) |
| "기도 템플릿 폴더를 찾을 수 없습니다" / "기도 폴더에 PPT 파일이 없습니다" | ⚙ 설정 → 폴더의 `기도` 줄에서 폴더 지정, 기도 종류별 PPT 넣기 (4-2 참고) |
| "기도 템플릿 폴더에 '기도.pptx' 없음" | 예전 프리셋의 기도 항목 → 항목을 클릭해 기도 종류를 다시 고르기 |
| "설교 템플릿 PPT 가 설정되지 않았거나…" | ⚙ 설정에서 설교 템플릿 PPT 지정 (4-2 참고) |
| "Bible2PPT.exe 경로가 설정되지 않았습니다" | ⚙ 설정에서 exe 경로 지정 |
| 성경 PPT 생성 실패 (인자 오류) | 구절 형식과 역본 이름 확인, ↻로 역본 목록을 다시 불러오기 |
| "출력 폴더가 … 폴더와 같거나 그 안에 있어…" | 원본을 덮어쓰지 않도록 출력 폴더는 템플릿·기도·찬송가·CCM 폴더 밖으로 지정 |
| "성경 템플릿은 .pptx 파일만…" | 성경 템플릿은 매크로가 없는 .pptx 만 사용 가능 |
| "결과 파일을 덮어쓸 수 없습니다" / "저장할 수 없습니다" | 같은 이름의 결과 파일이 PowerPoint에서 열려 있으면 닫고 다시 시도. 닫지 않고 확인만 하려면 [미리 보기 (저장 안 함)] |
| 이름이 들어가지 않음 (로그에 ⚠) | 템플릿에 `{{내용1}}`(설교자는 `{{내용2}}`)을 넣거나 텍스트 상자 이름을 `내용1`/`내용2`로 지정 |
| "슬라이드 크기가 다릅니다" 경고 | 첫 번째 순서 PPT 크기(16:9/4:3)로 맞춰집니다. ⚙ 설정의 **슬라이드 비율**을 16:9나 4:3으로 고르거나 템플릿 크기를 통일하면 사라짐 |
| PowerPoint를 실행할 수 없음 | PowerPoint 설치·정품 인증 상태 확인, 열려 있는 대화 상자가 있으면 닫기 |
| "…PowerPoint 에서 열려 있어 저장된 내용으로 만듭니다" 경고 | 고치던 템플릿을 저장하지 않고 생성함 → 고친 내용을 넣으려면 템플릿을 **저장**한 뒤 다시 생성 (열어 둔 문서는 그대로 둠) |
| 생성 중 "진행이 없습니다" 안내 | **[PowerPoint 창 보기]** → 라이선스 동의·로그인·오류 창을 닫기. 그래도 그대로면 **[생성 중단]**. Office 를 처음 설치했으면 PowerPoint 를 한 번 직접 켜서 안내 창을 모두 닫아 두기 |
| "암호가 걸린 PPT 는 사용할 수 없습니다" | 그 PPT 를 PowerPoint 로 열어 [파일] → [정보] → [프레젠테이션 보호]에서 암호를 지우고 저장 |
| "설정 저장 불가" (시작할 때·설정을 저장할 때) | 프로그램 폴더에 쓸 수 없음(`C:\Program Files` 등) → 문서 폴더처럼 쓸 수 있는 곳으로 프로그램을 옮기기 |
| "설정 파일을 읽을 수 없음" (시작할 때) | `config.json`·`presets.json` 이 손상돼 기본값으로 시작함. 원래 파일은 같은 폴더에 `config.json.broken` 처럼 보관되므로 고쳐서 이름을 되돌리면 됨. 메모장으로 고칠 때 인코딩(UTF-8·BOM·ANSI·유니코드)은 무엇이든 읽음 |
| 버튼을 눌러도 반응이 없음 / "프로그램 오류가 났습니다" | 예상하지 못한 오류 — **[로그]**에 내용이 남습니다 (파일로 저장되지는 않으므로 닫기 전에 확인) |
| "프로그램이 이미 실행 중입니다" | 한 번에 하나만 실행됩니다 (두 창이 설정을 서로 덮어쓰거나 생성이 섞이지 않게). 보통은 이미 떠 있는 창이 앞으로 나옵니다 |

> 원본 템플릿·찬송가·CCM 파일은 **읽기 전용으로만 열기** 때문에 절대 수정되지 않습니다.
> PPT 안의 매크로는 실행되지 않도록 막지만, **출처를 알 수 없는 PPT 파일**은 템플릿·찬송가·CCM 폴더에 넣지 마세요.

## 9. 파일 구성

```
ChurchPPTMaker/
├─ main.py             메인 화면
├─ ui_widgets.py       달력, 입력 창, 설정 창, 드래그&드롭 등 화면 부품
├─ ppt_engine.py       PowerPoint 병합 엔진 (win32com)
├─ worship_builder.py  생성 과정 (파일 찾기 → 성경 PPT 생성 → 병합 → 파일 이름)
├─ bible_bridge.py     Bible2PPT 연동
├─ config_manager.py   설정·프리셋 저장
├─ models.py           순서 항목 정의
├─ requirements.txt    필요한 Python 패키지
├─ requirements-build.txt  빌드용 패키지 (requirements.txt + PyInstaller)
├─ build.bat / build.ps1   exe 빌드 스크립트
├─ version.py              프로그램 버전 (화면 제목·exe 속성)
├─ assets/app.ico         프로그램 아이콘
└─ CLAUDE.md           개발용 상세 문서 (구조·규칙·개발 히스토리)
```

개발 규칙과 내부 구조는 [CLAUDE.md](CLAUDE.md)를 참고하세요.
